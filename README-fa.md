# 🎧 سونورا — عمیق‌تر گوش کن.

پخش‌کنندهٔ موسیقی با تم تیره و لهجهٔ طلایی، همراه با یک بک‌اند کامل روی
Cloudflare که فایل صوتی را از تلگرام می‌گیرد و کاتالوگ زنده منتشر می‌کند.

## ✨ امکانات

- **پخش‌کننده** — پخش واقعی صدا، پلی‌لیست، کتابخانه، آمار شنیدن محلی،
  اکولایزر ۱۰ باندی، و خواندن تگ‌های ID3 و کاور جاسازی‌شده در مرورگر.
- **کاتالوگ ابری** — اگر `window.SONORA_API` تنظیم شود، پخش‌کننده از
  `GET /api/manifest.json` می‌خواند؛ در غیر این صورت از فایل ثابت و خالیِ
  `audio/manifest.json` استفاده می‌کند.
- **ورود از تلگرام** — وبهوک، کارها را در صف می‌گذارد؛ پیام صف فقط شناسه دارد و
  هرگز فایل صوتی.
- **خط تولید** — دانلود ← تشخیص مدت ← تگ‌ها ← R2 ← آرشیو دراپ‌باکس ← متن آهنگ ←
  انتشار، با ثبت وضعیت پایدار در هر مرحله.
- **متن آهنگ** — اگر SYLT یا USLT جاسازی‌شده باشد همان استفاده می‌شود؛ وگرنه
  Whisper روی Workers AI و سپس پاک‌سازی محافظه‌کارانه با Qwen، بدون تغییر زمان‌بندی.
- **پنل مدیریت** — ترک‌ها، منابع، حساب‌های دراپ‌باکس، خطاها و سلامت سیستم؛ از خودِ
  Worker سرو می‌شود تا نشست هم‌مبدأ بماند.

## 🧩 اجزای اصلی

| | |
|---|---|
| `index.html`، `css/`، `js/` | پخش‌کنندهٔ ثابت، بدون فریم‌ورک و بدون مرحلهٔ build |
| `audio/manifest.json` | کاتالوگ جایگزین آفلاین (در ابتدا خالی) |
| `cloud/worker/` | Worker کلادفلر: مسیرها، سرویس‌ها، کارها، مایگریشن‌های D1، تست‌ها |
| `cloud/worker/public/admin/` | رابط مدیریت که توسط Worker سرو می‌شود |
| `docs/` | مستندات فنی برای عامل‌های کدنویس |

## 🚀 شروع سریع

```bash
# پخش‌کننده — بدون نصب
python3 -m http.server 8080          # http://localhost:8080

# بک‌اند
cd cloud/worker
npm install
cp .dev.vars.example .dev.vars       # مقادیر نمونه را پر کنید؛ هرگز commit نشود
npm run migrate:local
npm run dev                          # پنل مدیریت در /admin/
```

## 🧪 تست‌ها

```bash
cd cloud/worker
npm test        # بدون شبکه، سرویس‌ها mock شده‌اند
npm run build   # بررسی باندل با dry-run رنگر
```

## 🔐 نکتهٔ امنیتی

فایل `.dev.vars` یا توکن واقعی را هرگز commit نکنید. تست‌ها و build به‌صورت
عمدی آفلاین‌اند؛ اتصال واقعی به سرویس‌دهنده‌ها فقط با `GET /api/health` روی
Worker مستقرشده اثبات می‌شود. جزئیات در [`docs/OPERATIONS.md`](docs/OPERATIONS.md).
